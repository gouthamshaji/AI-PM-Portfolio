## Workflow Overview

An automated workflow that receives stock ticker symbols and delivers comprehensive investment analysis via email.

## How It Works

1. User sends stock ticker via chat interface
2. Workflow fetches stock data from financial APIs
3. AI analyzes technical and fundamental indicators
4. Comprehensive report generated
5. Email delivered with analysis and recommendations

## Key Features

- Chat-based trigger interface
- Technical & fundamental analysis
- Clear recommendations with confidence scores
- Automated email delivery
