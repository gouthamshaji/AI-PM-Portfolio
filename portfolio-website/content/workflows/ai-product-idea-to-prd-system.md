## Workflow Overview

A sophisticated multi-agent pipeline that transforms raw product ideas into comprehensive, actionable PRDs in under 5 minutes.

## How It Works

1. User submits product idea via Google Sheet
2. Ideation Agent refines concepts and generates alternatives
3. Market Analysis Agent estimates TAM/SAM and competitive landscape
4. Prioritization Agent scores using ICE framework
5. Roadmap Agent creates phased execution plan
6. Complete PRD output with success metrics

## Multi-Agent Architecture

- Ideation Agent - Refines concepts, identifies core problems
- Market Analysis Agent - TAM/SAM estimation, competitive analysis
- Prioritization Agent - ICE scoring, business value assessment
- Roadmap Agent - MVP through scale phases, team requirements
