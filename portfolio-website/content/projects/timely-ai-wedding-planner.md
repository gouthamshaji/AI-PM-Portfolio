## Overview

A smart planning assistant for Indian weddings that generates personalized task timelines and tracks dependencies.

## Key Features

- AI-generated week-by-week task plans
- Dependency tracking (blocked tasks)
- Multi-event support (Mehendi, Sangeet, Haldi, Wedding, Reception)
- India-specific cultural context
- Collaborative planning

## Tech Stack

- Next.js 15, React, TypeScript
- Supabase (database)
- Anthropic Claude API
- Tailwind CSS
