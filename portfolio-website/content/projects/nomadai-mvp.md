## Overview

A travel companion application that helps remote workers and digital nomads discover optimal destinations based on their lifestyle preferences.

## Key Features

- Location-based recommendations
- Lifestyle preference matching
- Cost of living data
- Community features
- Remote work infrastructure ratings

## Tech Stack

- Next.js, React, TypeScript
- Tailwind CSS
- Location-based services
